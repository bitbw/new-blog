# 介绍

这是我的个人技术知识库，记录日常开发中反复查阅、验证和沉淀下来的内容。

这里既有可以直接复制使用的命令和配置，也有对原理、问题排查和项目实践的整理。内容会持续更新，但不追求把所有资料都写成完整教程，重点是留下真正对工作有帮助的记录。

## 从这里开始

- [AI 工具](/docs/AI/AI工具/常用AI工具汇总/)：模型、编程辅助和日常 AI 工具。
- [前端](/docs/前端/JavaScript/es6模块规范/)：JavaScript、Vue、React、Node.js 和工程化。
- [Git 与 GitHub](/docs/Git/Git-常用命令/)：版本控制、自动化和代码托管。
- 开发运维工具：常用工具、部署和开发环境配置，可从左侧目录展开。
- [操作系统](/docs/OS/Windows/windows系统常见问题/)：Windows、Linux、macOS 相关记录。
- 数据库：数据库使用和问题排查，可从左侧目录展开。
- 网络知识：网络、接口和常见基础概念，可从左侧目录展开。

## 怎么使用

- 想快速解决问题，先使用左侧目录按主题查找。
- 想了解最近的实践过程，可以查看顶部的 Writing。
- 文档中的命令和配置以当前项目为背景，使用前请结合自己的环境确认路径、版本和权限。

## 内容边界

Notes 更偏向长期可查的知识和操作记录；Writing 更偏向具体项目、工具实践和阶段性思考。两者会互相链接，但不会重复维护同一份内容。
