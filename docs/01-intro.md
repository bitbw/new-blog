# Notes：从这里开始

这是我的个人技术知识库，记录日常开发中反复查阅、验证和沉淀下来的内容。Notes 偏向长期可查的知识和操作记录；顶部的 Writing 偏向项目实践、工具分享和阶段性思考。

这里既有可以直接复制使用的命令和配置，也有对原理、问题排查和项目实践的整理。旧文章会继续保留，但涉及旧版本的内容会逐步标记为历史资料。

## Notes 和 Writing 怎么选

- 想快速解决问题，先从左侧目录按主题查找 Notes。
- 想了解最近的项目过程、AI 工具实践或技术观点，查看顶部的 Writing。
- 想看历史内容，可以先阅读[内容整理方案](/docs/站点整理/博客与%20Notes%20整理方案/)，了解维护状态和后续整理计划。
- 想按系列阅读文章，可以查看 [Writing 系列索引](/docs/站点整理/Writing%20系列索引/)。
- 想查看旧版本笔记，可以查看 [历史内容与版本说明](/docs/站点整理/历史内容/)。
- 文档中的命令和配置以当前项目为背景，使用前请结合自己的环境确认路径、版本和权限。

- 文档中的命令和配置以当前项目或当时的开发环境为背景，使用前请确认自己的路径、版本和权限。
- 旧技术文章可能只适用于特定版本；遇到版本差异时，优先查看官方文档和文章中的适用范围。
